# Edge-Browser-Backup

一个运行在本机的 Edge / Chromium 扩展，用来把**标签页组、收藏夹、已安装扩展**备份到插件自己的文件夹里，并在插件内管理、还原和删除这些备份。

不联网、不上传任何数据，所有读写都在本机完成。

- 当前版本：**1.9.0**
- 下载：见 [Releases](https://github.com/CXH888888/Edge-Browser-Backup-Expansion/releases)

---

## 一、它能做什么

| 能力 | 说明 |
|---|---|
| 完整备份 | 一份 JSON 同时保存标签组与收藏夹：组名、颜色、折叠状态、成员顺序、收藏页全部层级 |
| 还原 | 在新窗口重建标签组，收藏夹可合并或装进新文件夹，重复执行不会产生重复项 |
| 扩展盘点 | 读取已安装扩展的名称、版本、类型、启用状态，可导出 CSV |
| 扩展源码备份 | 把扩展的源码复制进备份目录，被下架或作者弃坑时仍能装回 |
| 备份管理 | 按类型分组、折叠、可滚动查看，带图标与体积统计 |
| 回收站 | 删除先进入回收站，可恢复或彻底删除 |
| 整体迁移 | 备份跟着插件目录走，换电脑拷一个文件夹即可 |

## 二、安装

1. 到 [Releases](https://github.com/CXH888888/Edge-Browser-Backup-Expansion/releases) 下载最新的 `Edge-browser-backup-vX.Y.Z.zip`，解压。
2. 把解压出来的 `Edge-browser-backup` 文件夹放到一个**不会被移动、且可写**的位置（例如 `~/Apps/`）。
   > 扩展加载后与路径绑定：移动或改名后需要重新加载。
3. 打开 Edge，地址栏输入 `edge://extensions/`。
4. 打开左下角的 **开发人员模式**。
5. 点击 **加载解压缩的扩展**，选中第 2 步的文件夹。
6. 安装后会自动打开主界面；之后点工具栏的扩展图标即可再次打开。

## 三、第一次使用（三步）

### 第 1 步：备份标签组与收藏夹

打开「标签与收藏」页签，点 **备份到插件目录（.json）**。

- 会生成 `backups/完整备份/edge-backup-日期时间.json`
- 一份文件里同时包含标签组和收藏夹，不需要分两次
- 按钮下方会显示当前备份位置

如果提示未授权，先做第 3 步。

### 第 2 步：备份扩展源码

在 Finder 里双击插件目录下的 **`备份扩展源码.command`**。

- 它会从 Edge 的配置目录把扩展源码复制到 `backups/扩展源码/<扩展名>-<ID前8位>/`
- 会自动跳过 `_metadata`，按 manifest 读取真实名称与版本（支持多语言名称）
- 同一扩展的旧副本会先清掉，不会出现两份

> 为什么不能直接在界面里选目录？  
> Edge 的扩展目录位于浏览器配置目录内，Chromium 按设计**禁止扩展通过文件选择器授权这类路径**，会提示「此文件夹包含系统文件」。这是浏览器的安全策略，扩展无法绕过，所以复制这一步交给脚本在浏览器外完成。

### 第 3 步：授权插件目录

进入「备份管理」页签，点 **授权插件目录**，选中放着 `manifest.json` 的那个文件夹。

- 授权后插件才能读取备份列表、显示体积、删除备份
- 浏览器重启后若权限失效，点一次「恢复授权」即可，不用重新选目录

完成后回到「备份管理」点 **刷新**，第 2 步复制进来的扩展就会出现在列表里。

## 四、三个页签

### 标签与收藏

- **当前快照**：窗口 / 标签组 / 标签页 / 收藏项数量
- **备份与导出**：主按钮写进插件目录；三个「导出」才是下载到浏览器默认下载文件夹
- **导入**：选择或拖入 `.json`，先出预览再还原
- **进阶设置**：导出范围、还原行为、备份提醒（改动即时生效并记住）
- **执行记录**：每一步操作的结果

### 扩展

只读盘点，不写磁盘。

- 列表带图标、名称、版本、类型、状态
- 勾选后可「导出清单」（CSV，Excel 直接打开不乱码）

### 备份管理

- **备份位置**：脚本说明 + 授权插件目录
- **已有备份**：分「扩展源码」和「完整备份」两组，默认收起，点标题展开；每组最多展示 6 行，超出在组内滚动；标题右侧显示数量与体积
- **回收站**：删除的项目暂存于此，可恢复、彻底删除或清空

## 五、备份存在哪

全部备份都在插件目录内，跟着插件走：

```
Edge-browser-backup/
├── manifest.json
├── app.html / app.js / app.css / ext.js
├── 备份扩展源码.command
└── backups/
    ├── 完整备份/edge-backup-日期时间.json
    ├── 扩展源码/<扩展名>-<ID前8位>/
    ├── .回收站/<时间>-<名称>/
    └── 位置.txt            脚本写入，记录插件目录的绝对路径
```

**迁移到新电脑**：退出 Edge → 整个拷走这个文件夹 → 新机器加载扩展 → 授权插件目录 → 备份列表立刻可见。

## 六、还原

1. 「标签与收藏」→ 导入 → 选择 `backups/完整备份/` 里的 json
2. 下方出现恢复预览：导出时间、窗口/组/标签/收藏数量、各组名称与颜色
3. 勾选要还原的内容：
   - **还原标签组**：在新窗口重建，不动当前窗口
   - **还原收藏夹**：*合并到原位置*（相同网址跳过，可重复执行）或 *装进新文件夹*
4. 点「开始还原」

> `edge://` 内部页面无法由扩展重新打开，还原时会自动跳过并计数。

---

## 七、删除与回收站

- 每行的「删除」只是把项目移入 `backups/.回收站/`，不会立刻消失
- 回收站里可以 **恢复**（放回原位置，重名会拒绝）或 **彻底删除**
- 「清空回收站」才会真正从磁盘移除

> 浏览器沙箱到不了系统 Finder 的废纸篓，所以回收站做在插件目录内。

---

## 八、权限与隐私

`manifest.json` 声明的权限：

| 权限 | 用途 |
|---|---|
| `tabs` / `tabGroups` | 读取标签页与标签组的名称、颜色、顺序 |
| `bookmarks` | 读取与还原收藏夹层级 |
| `storage` | 记住勾选、设置、折叠状态 |
| `management` | 读取已安装扩展的清单 |

- 没有任何网络请求，代码里没有 `fetch` / `XMLHttpRequest`
- 文件读写只发生在你手动授权的那一个文件夹

## 九、常见问题

**为什么扩展图标有的是字母块？**  
其他扩展的图标文件不允许跨扩展读取。插件会从**备份源码里的 manifest 图标**读真实 logo；没备份过、或扩展已卸载时，用名称首字母色块代替。

**为什么脚本里的扩展名曾经显示成 `APP_NAME`？**  
1.9.0 之前的版本对多语言 manifest（`__MSG_xxx__`）解析不完整。现在会依次尝试 `default_locale`、`zh_CN`、`zh`、`en` 与其他语言包。重新跑一次脚本即可修正名称。

**双击脚本提示无法验证开发者？**  
右键 →「打开」。脚本只做本地文件复制，可以打开文本编辑器自行检查。

**备份会占多少空间？**  
扩展源码通常几十到几百 MB，可在备份管理里看到实测量。

**卸载扩展后备份还在吗？**  
在。备份在插件目录里，移除扩展不会删除文件，重新加载后仍可读取。

**能备份到网盘目录吗？**  
可以，但需要授权的是**插件目录本身**。备份位置固定在其中，方便整体迁移。

## 十、开发

```
Edge-browser-backup/
├── manifest.json          MV3 清单
├── background.js          点击图标打开主界面
├── app.html / app.css     界面与样式（跟随系统明暗主题）
├── app.js                 标签与收藏：采集 / 备份 / 导出 / 还原 / 设置
├── ext.js                 扩展盘点 / 备份位置 / 扫描 / 删除
├── 备份扩展源码.command    浏览器外复制扩展源码 + 写位置.txt
└── backups/               运行时生成，已在 .gitignore 中排除
```

发版：

```bash
# 1. 改 manifest.json 的 version
git add -A && git commit -m "..." && git push

# 2. 打包（排除本机备份数据）并发布
cd .. && zip -r -X dist/Edge-browser-backup-vX.Y.Z.zip Edge-browser-backup \
  -x "Edge-browser-backup/backups/*" -x "Edge-browser-backup/.git/*" -x "*.DS_Store"
gh release create vX.Y.Z dist/Edge-browser-backup-vX.Y.Z.zip --title "..." --notes-file notes.md
```
